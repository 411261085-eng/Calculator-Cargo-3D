# Kalkulator Cargo 3D

Perencana muatan 3D untuk container dan truk (Fuso, Tronton, Trailer, termasuk versi tanpa bak).
Aplikasi web progresif (PWA): bisa dibuka online dan dipasang di PC atau HP.

## Fitur
- Visual 3D container dan kendaraan, putar dan zoom
- Denah 2D, tampak samping, dan laporan muatan (cetak / PDF)
- Atur posisi cargo manual: seret di 3D atau denah, tumpuk otomatis, kolom X/Y, tombol geser
- Impor daftar barang dari Excel / CSV
- Bisa diinstal dan tetap jalan tanpa internet setelah dibuka sekali

## Memasang di PC
Buka alamat situs di Chrome atau Edge, lalu klik ikon pasang di kanan address bar
atau tombol "Pasang Aplikasi" di pojok kanan atas aplikasi.
